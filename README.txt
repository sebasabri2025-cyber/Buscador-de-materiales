BUSCADOR DE MATERIALES - PWA

Esta carpeta contiene una versión instalable como aplicación web (PWA).
Incluye los 1.696 materiales del archivo Excel original.

Para instalarla en Android:
1. Los archivos deben estar publicados en un sitio web con HTTPS.
2. Abrir index.html desde ese sitio con Chrome.
3. Chrome mostrará "Instalar aplicación" / "Agregar a pantalla principal".
4. Instalar.

Importante: abrir el HTML directamente como archivo local no siempre permite instalar una PWA.
